# Baccarat Telegram Casino

Игра Baccarat для Telegram с использованием Web App и Telegram Stars.

## Функции
- Покупка фишек за Stars.
- Игра в Baccarat.
- Хранение баланса пользователей.

## Запуск
- `python api.py` — запуск API.
- `python bot.py` — запуск бота.

## Требования
- Python 3.8+
- aiogram, flask, python-dotenv
